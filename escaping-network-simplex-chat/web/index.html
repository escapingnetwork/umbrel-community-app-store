Quick Setup

Configure Hermes Agent

1
Install Hermes Agent on Umbrel
Make sure the Hermes Agent app (or container) is running on the same Umbrel instance.
2
Set the WebSocket URL in Hermes
SIMPLEX_WS_URL=ws://simplex-chat_app_1:5225
You can also use the exports.sh variable when Hermes supports it as a dependency.
3
Pair your agent (recommended)
Run hermes gateway pair or use the setup wizard. Hermes will message the gateway and receive a pairing code.
Privacy

All communication stays on your Umbrel. No phone numbers, emails, or persistent user IDs are exposed to the SimpleX network.

Multiple Clients

The daemon supports multiple simultaneous connections (Hermes + debug tools + future agents).

Debug

Use Umbrel's Terminal app:
docker exec -it simplex-chat_app_1 simplex-chat -d /data
